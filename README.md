# TURBO RUSH

Jogo de corrida arcade 2D (3 voltas, nitro, obstaculos).

## Versao Python (Pygame)
    pip install pygame
    python3 turbo_rush.py
Controles: WASD dirige, SHIFT nitro, ESC pausa. Teste: `python3 test_turbo_rush.py`

## Versao navegador
Abra `turbo_rush.html` no navegador (arquivo unico, sem internet).
Sempre 2 jogadores em tela dividida (J1: WASD + Shift esq; J2: setas + Shift dir) e 4 cenarios: praia, deserto, mar e cidade.
